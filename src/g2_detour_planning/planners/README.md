# G2 绕障规划器的候选路径与验证

给定同一组起点关节角与目标位姿，规划器的差别首先在于「到哪里试下一步」。一条候选边能否延伸，还取决于走到当前节点时的肘部构型。这里的末端搜索因此同时保存末端位置和实际关节角。[返回绕障规划](../README.md) · [请求与结果类型](./_types.py)

## 候选点从哪里来

| 方法 | 候选生成与选择 | 实现 |
| --- | --- | --- |
| 模板枚举 | 在起终点连线的垂直平面内取 8 个方向，偏移距离取 8、12、18、25、33、42 cm。V 形在中点绕开，梯形用两个中间点拉长侧移段，U 形先横移再平行前进。按折线路程从短到长验证，返回第一个可行模板。 | [via_points](via_points.py) |
| 模板接随机树 | 在同一检查器中先走直达与模板，再用剩余时间和边数预算试末端 RRT。适合先试常见翻越动作，再尝试不规则通道。 | [via_then_rrt](via_then_rrt.py) |
| 末端随机树 | 在起终点包围盒各向外扩 35 cm 的范围内采点，20% 的采样直接指向目标。树每次从最近节点走至多 10 cm，靠近目标才验证最后一段。固定随机种子，成功后沿树回溯并验证捷径。 | [ee_rrt](ee_rrt.py) |
| 模板接网格 | 最多试 40 个通过整条折线粗筛的模板。转入加权 A* 时创建新的检查器，重新检查目标与直达，最后合并两阶段的统计。 | [via_then_astar](via_then_astar.py) |
| 标准权重 A* | 用累计代价和剩余直线距离安排搜索次序。权重 1 对目标方向的偏好较弱，适合观察搜索范围和开销。 | [astar_w1](astar_w1.py) |
| 加权 A* | 把剩余直线距离乘以 2.5，提高目标方向的优先级，作为其余网格变体的比较基线。 | [astar_w25](astar_w25.py) |
| 离障 A* | 在权重 2.5 上增加离障罚分。格点距最近障碍点小于 20 cm 时，越近罚分越高，搜索会倾向较宽的通道。 | [astar_clear](astar_clear.py) |
| Theta* | 在权重 2.5 的网格上，格点出队时先试从祖父节点跨过父节点直连。连得上时即可在搜索过程中减少折点。 | [theta_star](theta_star.py) |
| 关节空间双向树 | 从当前构型和无碰撞目标 IK 解分别长树，单次扩展至多 0.3 rad，轮流向另一棵树连接。对每条关节边查碰撞，并尝试随机捷径。返回路点由正运动学计算，便于量化末端绕了多远。 | [joint_rrt](joint_rrt.py) |

四种网格方法共用 5 cm、26 邻域的格点。邻居入队时只估计代价，出队时才花时间做 IK 和碰撞检查。成功连边后，累计代价还计入整段的关节转角。接近目标 1.5 个网格间距时会尝试直达目标，成功后沿路径寻找能跨越最多中间点的捷径。[网格搜索](./_grid.py) · [捷径验证](./_edges.py)

## 一条候选边如何通过

1. **目标与粗筛。** 先用多种子 IK 检查完整目标位姿是否可达、是否至少有一个无碰撞解。对候选线段约每 2.5 cm 取一个末端点，距离障碍点不足 10 cm 就拒绝。离全程起点或终点 12 cm 内的采样跳过粗筛，以允许接近目标物体，后续的关节路径仍要查碰撞。[目标检查与末端粗筛](./_edges.py)
2. **求关节路径。** 默认用积分笛卡尔从上一段实际关节角推进，在零空间向目标可行构型牵引。遇到关节限位或奇异点，可改用局部 IK 加关节插值，要求中间点偏离目标直线不超过 3 cm 与段长 15% 中较大者。还到不了中间路点时，依次尝试只保工具 X 轴朝向、只保位置。最后一个路点仍按完整目标姿态求解。[段求解与回退](./_edges.py) · [雅可比求解与关节限位](../../g2_arm_ik/algorithms.py)
3. **查行程与碰撞。** `path_sane` 拒绝关节总转角过大的回环。检查器再沿关节路径按最大单关节变化 2° 的间距补点，以请求提供的 `valid(q)` 检查每个构型。若直达尝试因 IK 失败，检查器还可尝试直接插值到目标 IK 解，并检查回环和碰撞。[行程与碰撞实现](./_edges.py)

## 怎样读失败结果

`PlanResult.joint_path` 为 `None` 时看 `note` 和 `stats`。`prefilter_reject` 表示候选线段靠障碍点太近，`ik_reject` 表示求解器没有走到候选位姿，`sane_reject` 表示回环检查失败，`collision_reject` 表示求出的路径中有构型被碰撞回调拒绝。若粗筛几乎没有拒绝而碰撞拒绝很多，可对照虚拟碰撞体是否进入了障碍点集，以及大件附着物的宽度是否超出末端点粗筛能表达的范围。[统计字段](./_edges.py) · [障碍点来源](../arm_motion.py) · [附着物几何](../tools/README.md)

默认每个检查器在搜索循环中按 8 秒或 1,500 条昂贵边结束搜索，先达到者生效。单次 IK、碰撞回调和最后的捷径处理都可能使实际耗时越过该阈值。注册器通过 `@register` 发现模块，返回可用方法及各模块的加载错误。默认名称保存在包入口。[预算检查](./_edges.py) · [注册发现](./_registry.py) · [默认方法](./__init__.py)
