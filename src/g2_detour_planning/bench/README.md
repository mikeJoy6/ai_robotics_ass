# G2 右臂绕障评测的场景与判分

这组资产把一次观测固定下来，让不同规划器面对同一堵障碍、同一个起点、同一个目标。题目给出右臂起始关节角和目标末端位姿，每个规划器自行求目标 IK。其余关节保持快照姿态。采样、复查和汇总均可沿源码阅读。[返回绕障规划](../README.md) · [生成与评测程序](../planner_bench.py) · [九种规划器](../planners/README.md)

## 快照保存了什么

| 资产 | 坐标与单位 | 评测如何使用 |
| --- | --- | --- |
| [占据体素中心](octomap_0428_base_link.npy) | `float64` 数组，5,867 行、3 列，每行是 `base_link` 系下的 x、y、z，单位为米，体素边长 3 cm。 | `real` 场景把点换到 `arm_base_link` 系，再剔除距快照右臂表面采样点 6 cm 以内的残留自体点。 |
| [同一时刻的全身关节角](snapshot_joints.json) | `joints` 按名称保存关节角，单位为弧度。来源字段记录了 2026-11-02 04:28 的原始采集。 | 固定头、腰与另一只手臂，为每道题提供同一个身体姿态。右臂起终构型在快照关节角周围随机采样。 |

## 四个场景各测什么

| 场景 | 障碍如何生成 | 检验的问题 |
| --- | --- | --- |
| `real` | 使用清理后的实测体素。 | 面对形状不规则的真实障碍时，能否找出路径。 |
| `box` | 生成 0.72 m 高的桌面，把宽度和高度随机的箱子放在 A、B 中间。 | 手臂能否翻过或绕过挡住直达路线的箱子。 |
| `wall` | 在 A、B 中间放一块悬空竖板，让板面横挡通路。 | 能否从上方、下方或侧面找到可行通道。 |
| `free` | 保留身体碰撞模型，移除环境障碍。 | 在空旷环境中，直达处理需要多少开销。 |

出题器用固定种子抽取距起点 20 至 55 cm 的目标，用参考起终关节角线性插值、每 4° 检查一次来标记「绕障题」。`box` 和 `wall` 只保留这种直连受阻的题目。`real` 按快照实际情况分类。这个标签描述的是参考关节直连的结果，其他 IK 分支仍可能直达。[题目生成与分类](../planner_bench.py)

## 成功率、离障与耗时怎么看

- **成功**要求复查时关节路径每 2° 采样均可行，终点位置误差小于 5 mm，姿态误差小于 1°。离线世界将链接几何转成凸包，结合 SRDF 的碰撞豁免、自体和环境体素做离散判定。[判分代码](../planner_bench.py) · [凸包与体素检查](../sim_world.py)
- **路线质量**用末端路程与直线距离之比、关节累计转角、末端最远横向偏移及臂离障距离来衡量。另有一个半径 8 cm 的球近似手部，手部离障为负表示球代理侵入障碍。该指标单独记录，评测的成功条件按上面的路径与位姿复查计算。[离障计算](../sim_world.py) · [指标汇总](../planner_bench.py)
- **执行时长**来自按关节速度与加速度约束算出的轨迹时标。评测按关节轨迹控制器的三次样条复算速度与加速度峰值。汇总路线质量时，绕障成功率至少 70% 的方法在共同解出的题上比较，带星号的方法则只统计各自解出的绕障题。[轨迹计时](../arm_motion.py) · [比较子集与输出字段](../planner_bench.py)
