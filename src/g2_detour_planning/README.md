# G2 手臂怎样绕过障碍到达目标位姿

假设右臂要越过桌上的箱子，让吸盘以指定朝向到达另一侧。终点逆运动学（IK）回答「到了那里，各关节可以转到什么角度」。绕障规划还要回答「从现在的关节角出发，手和肘能沿哪条路过去」。这里收录 G2 原工程的九种规划器、它们共用的碰撞检查方法，以及把路径变成定时轨迹的参考实现。

## 同一个目标，九种选路方法

规划器接收当前关节角、目标位置与朝向、逆运动学求解器和碰撞判定函数，也可接收粗筛用的障碍点。位置与朝向统一在手臂根坐标系 `arm_base_link` 表达。成功时返回关节路径、用于展示的末端路点及统计，失败时可从 `note` 查看原因。末端空间规划器先检查目标有没有无碰撞 IK 解，再尝试直达。[请求与返回值](planners/_types.py) · [共用检查实现](planners/_edges.py)

| 规划器 | 它怎样找路 | 适合研究的问题 |
| --- | --- | --- |
| [via_then_rrt](planners/via_then_rrt.py) | 先试 V 形、梯形和 U 形绕行模板，按末端路程从短到长验证。模板走不通时用剩余预算生长末端随机树。 | 原工程的默认选择。常见障碍可用一两个中间点绕过，复杂通道还可继续搜索。 |
| [via_points](planners/via_points.py) | 沿起终点连线周围取八个方向、六个偏移距离，枚举三种折线，返回首条全部通过的候选。 | 想知道固定模板能解决多少问题。需要连续换方向的通道可能没有合适模板。 |
| [ee_rrt](planners/ee_rrt.py) | 在末端空间采样，选最近树节点扩展至多 10 cm，再试着接上目标。成功后删除能直连的中间点。 | 研究模板覆盖以外的路线，以及随机树需要做多少次 IK 和碰撞检查。 |
| [via_then_astar](planners/via_then_astar.py) | 最多验证 40 个通过粗筛的模板，失败后转入启发权重为 2.5 的网格 A*。 | 比较网格与随机树作为第二阶段的效果。这里切换到网格时会重新计时。 |
| [astar_w1](planners/astar_w1.py) | 在 5 cm 网格上用到目标的直线距离作为启发值，格点出队时才验证路径。 | 比较较弱目标偏置的搜索开销。时间受限时，展开较多格点可能耗尽预算。 |
| [astar_w25](planners/astar_w25.py) | 将同一启发值乘以 2.5，优先检查看起来更接近目标的格点。 | 研究加大目标偏置后，规划时间和末端路程怎样变化。 |
| [astar_clear](planners/astar_clear.py) | 在加权 A* 中，对离最近障碍点不足 20 cm 的格点线性加罚。 | 需要比较贴障短路与较宽绕行路线。罚分改变选路偏好，最终碰撞仍逐段检查。 |
| [theta_star](planners/theta_star.py) | 在网格扩展时尝试从祖父节点直接连接新点，成功就跳过父节点。 | 减少网格方向造成的折点，观察多做一次直连检查能省下多少路程。 |
| [joint_rrt](planners/joint_rrt.py) | 选离当前关节角近的无碰撞目标 IK 解，在关节空间双向生长 RRT-Connect 树，再抄近路。 | 原工程用于对照 OMPL 思路的独立实现。它约束关节边可通行，末端可能扫过较大的范围。 |

原工程在三组留出题上比较过这些方法。默认算法通过了 196 道绕障题中的 183 道，规划耗时中位数为 0.58 秒。这些数字对应当时的模型、场景和时间预算。要判断手部余量、路径长度和耗时如何取舍，可从同题比较的口径读起。[默认值与历史记录](planners/__init__.py) · [离线评测口径](bench/README.md)

## 一段路怎样变成手臂轨迹

1. **从实际关节构型接着走。** 每个候选末端线段都从上一段结束时的关节角起步。检查器先用障碍点排除明显穿障的连线，再用积分笛卡尔求出连续的关节路径。七自由度带来的冗余可用于把肘部构型向终点的可行解牵引。局部积分失败时还可尝试小偏差关节插值，中间路点也允许逐级放宽朝向约束。[段验证与姿态调度](planners/_edges.py) · [手臂逆运动学](../g2_arm_ik/README.md)
2. **检查整条手臂和附着物。** 候选路径要通过关节行程检查，再逐点调用碰撞判定，相邻关节变化大于 2° 时补插值点。原 ROS 接口把候选手臂与反馈中的其余关节合并，查询时使用 `is_diff=True` 保留手上挂的物体。接口在碰撞服务未就绪时会警告并放行，已发出的查询超时则判为碰撞。阅读返回结果时需区分这两种状态。[ROS 碰撞适配](arm_motion.py#L364) · [离线碰撞模型](sim_world.py)
3. **给几何路径分配时间。** `cart_profile` 按平移与转角构成的弧长每 5 mm 重采样，用 3 cm 窗口平滑关节角，再前向限制加速、反向限制减速。默认末端平移巡航上限为 0.15 m/s，单关节速度取 URDF 限位，加速度阈值为 3 rad/s²。`cart_samples` 生成时间、关节角与速度，按控制器的三次样条复算加速度。平滑后碰撞检查失败时，调用方退回原路径重新计时。[时间参数化与采样](arm_motion.py#L165)

在适配层中，`plan_cartesian` 要求末端走直线。`plan_pose` 先求目标 IK，再试关节直连，直连有碰撞才调用绕障。即使直连阶段选了只约束工具轴的 `axis` 或只约束位置的 `pos`，绕障入口仍要求完整终点姿态。`plan_detour` 则直接交给所选规划器。原工程的 A/B 对照工具记录的是 `base_link` 系下的末端位姿，再通过实测腰部关节换算到手臂根系。[直连与绕障切换](arm_motion.py#L494) · [A/B 位姿对照](pose_ab_search.py)
