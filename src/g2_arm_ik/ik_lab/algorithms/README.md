# 同一个末端位姿，五种关节路径来源

这里注册了四种逆运动学（IK）策略和一种录制关节角回放。前四种从当前构型和目标工具位姿反求关节角，各自在初值的选取、单个初值的收敛方式和多解取舍上有所不同。

[框架如何验收路径](../README.md) · [G2 手臂与历史对比数据](../../README.md) · [统一接口](_types.py)

| 注册名 | 怎样找候选 | 怎样选出返回的路径 |
| --- | --- | --- |
| [ik](ik_direct.py) | 默认取排在前面的 3 个初值，对每个初值做固定小步 DLS，默认上限 100 轮。适合观察初值较少时局部逆解的表现。 | 每个收敛解各产生一条从起点直连的候选。公共层验证和排序。 |
| [multi_ik](multi_ik_direct.py) | 默认最多尝试 24 个确定性初值，为求解预留一半剩余时间。收集至多 5 个解，两解至少有一个关节相差 3° 才算不同。 | 逐解复核 FK 和限位，再按最大关节步幅 2° 采样各条直线。通过者中取各关节转角绝对值之和最小的一个，只将这条交给公共层。 |
| [multi_ik_adaptive](multi_ik_lm.py) | 保留 `multi_ik` 的初值、去重及选路方式，将单初值求解换成自适应 LM。误差较大时可以迈大步，遇到非线性误差或限位会收小步长。 | 与 `multi_ik` 使用同一套整段碰撞采样及总转角评分，可以用两者比较单次求解器的影响。 |
| [g2_seeded_lm](g2_seeded_lm.py) | 当前构型加默认 60 个随机初值，先用 KDL LMA 求完整位姿的粗解。最近 8 个解沿任务零空间向起点拉近，再重新排序。 | 取距离起点最近且通过状态检查的终点，自适应 LM 最多再精修 30 轮。收敛后交给公共层复核精度和整条直线，精修失败则返回空候选。 |
| [joint](joint_direct.py) | 从 `JointReplayRequest.goal_joints` 读取已录好的目标构型。 | 直接返回起点与录制角，供公共层评估。这给 A/B 回放提供已知答案的对照。 |

## 两种多初值策略为什么会选中不同的肘姿

`multi_ik` 系列从当前角、关节限位中点、任务零空间扰动和单关节偏移生成候选初值。当前角总是先试，其余按 FK 的目标位置误差、姿态误差和偏离起点的代价排序。初值是求解的出发点，成为候选解还要满足末端误差和限位。[确定性初值](_seeds.py) · [多解直连设计说明](multi_ik_direct.md)

`g2_seeded_lm` 先搜索随机初值，再用 `pull_near` 改善已有解。它沿局部零空间向起点走一步，用 LM 把末端拉回目标，保留通过容差且确实变近的构型。它按终点关节向量与起点的欧氏距离排序，`multi_ik` 则比较通过采样检查的直线的关节总转角。如果 `g2_seeded_lm` 所选终点的连接线被挡住，公共层会判该候选失败。[粗解与零空间拉近](../../algorithms.py) · [公共层路径检查](../planning.py)

## 自适应 LM 改善的是什么

固定小步 DLS 会逐分量截短误差，每轮只朝目标推进一小段。自适应 LM 用完整的位置、姿态误差求关节增量，用信赖域限制试探步，重新计算 FK 后才接受能减小误差的步子。遇到向外推的限位关节时冻结相应自由度，反复回退仍无改善时报告停滞。它返回一个终点解及其收敛原因，路径采样由外层完成。[自适应求解器](_adaptive_ik.py) · [数值方法设计说明](multi_ik_adaptive.md)

## 接入同一组比较

新算法继承 `Algorithm` 并实现 `plan(request)`，返回带标签的 `CandidatePath` 序列，每个路点是一整组关节角，序列包含实测起点和目标终点。在模块中使用 `@register` 后，`discover()` 会导入本目录下名称不以下划线开头的模块，收集可用算法及导入错误。G2 的公共请求支持 `full` 完整姿态。[请求与返回类型](_types.py) · [发现与注册](_registry.py)
